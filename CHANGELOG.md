# Journal des changements

Les versions publiées suivent Semantic Versioning. Les préversions peuvent évoluer et ne sont pas des versions stables.

## 1.0.0-preview.1

- Nouvelle base de l’application desktop Avalonia pour Windows et Linux.
- Création, reprise et archivage local de dossiers d’audit avec pages et référentiel choisi.
- Préparation des paquets Windows x64, Debian/Ubuntu x64 et RPM x86_64.
- Aperçu intégré limité à la fixture locale de démonstration ; la navigation réelle reste désactivée.
- Les paquets macOS de l’ancienne version ne sont pas reconduits dans cette préversion.
